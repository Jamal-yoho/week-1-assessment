# Week 1 Assessment

## Setup Instructions
1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies ising 'pip install -r requirements.txt'.
4. Run Python files from the 'src' folder.
5. Open 'notebooks/employee_analysis.ipynb' to view the analysis.

## Key Findings
1. Employee data contains missing salary values and duplicate records.
2. Missing salaries were filled using the median.
3. Duplicate employee record were removed.
4. Department-wise employee counts and salary averages were analyzed.
5. Bar, histogram, scatter and line charts were created.
